# Network

- Name: `timecoin-testnet`
- Chain id: `timecoin-testnet-1`
- 1 TIME = 100,000,000 base units
- Block reward: 50 TIME
- Genesis supply: 0
- Slot target: 600 seconds
- A child block must use a later slot than its parent

Genesis is domain-separated. Blocks from this testnet are not mainnet blocks. There is no peer-to-peer layer in this version. One local node checks every block itself.
